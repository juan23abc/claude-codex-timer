# Repository screenshots

These are window captures of the native SwiftUI app, using the debug-only sample-data mode from `./scripts/preview-screenshots.sh`.

- `overview.png`: the daily schedule and latest result for each provider.
- `settings.png`: provider selection, daily time, and separate CLI connections.
- `activity.png`: per-provider history.

The history and executable paths are examples, not live account results. No provider calls or real schedule changes are made for these captures. The release app does not enable this preview mode.
