Claude Codex Timer is a native Mac app that sends one small daily ping to Claude, Codex, or both, using your existing CLI sign-ins.

## Download and install

Download **ClaudeCodexTimer.dmg** from the assets below. Open it, drag **Claude Codex Timer** into **Applications**, eject the image, then launch the app.

- macOS **13 Ventura or later**.
- Universal app for **Apple silicon and Intel**.
- Requires [Claude Code](https://code.claude.com/docs/en/setup) and/or [Codex CLI](https://developers.openai.com/codex/cli), installed and signed in separately.

**First launch:** this build is ad-hoc signed and **not notarized by Apple**. If macOS blocks it and you trust the download, try opening it first, then select **System Settings → Privacy & Security → Open Anyway**. See [Apple’s instructions](https://support.apple.com/en-us/102445).

## Included

- Daily scheduling that runs when the app is closed.
- Claude, Codex, or both, with independent setup, tests, and results.
- Native SwiftUI interface and menu bar controls.
- Local activity history, visible failures, bounded execution, and no analytics.
- Consistent Claude Codex Timer naming and MIT licensing.

Existing settings, history, folder trust, and schedule identifiers are preserved. The app cannot guarantee when provider usage windows start or reset; pings consume account usage.

## Verification and limits

The 32 isolated tests pass. The app and helper build for both architectures, and the DMG and ad-hoc app signature are verified. Intel helper startup was checked under Rosetta; physical Intel hardware and macOS 13 have not been tested. A live Codex ping was verified during the earlier app review. A live successful Claude ping remains unverified because the tested account was at its usage limit. Repository screenshots use sample data.

Download the `.sha256` file alongside the DMG to verify it with `shasum -a 256 -c ClaudeCodexTimer.dmg.sha256`.
